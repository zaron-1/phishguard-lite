# PhishGuard Lite Roadmap

## Active task — session recovery and Cyber Academy progression

- [x] Recover persisted sessions after visibility changes, focus, sleep/wake, and temporary network loss without reloading the page.
- [x] Preserve the current route, lesson, audio state, and progress while auth rehydrates.
- [x] Extend Academy progression to Learning Path → Modules → Lessons → Subtopics → Quick Checks/Labs → Module Assessment.
- [x] Grow active learning paths to a sustained five-month study plan without replacing the existing catalog.
- [x] Automatically stop and load lesson audio on navigation, reading the lesson content and caching generated audio.
- [x] Add lightweight lesson visuals only where they improve comprehension.
- [x] Add backend-validated randomized module assessments, 80% unlock gates, retakes, and anti-copy friction.
- [x] Enforce one active learning path until completion in backend/database rules.
- [x] Autosave lesson, lab, module, and assessment progress for exact resume.

## Existing features to preserve

- PhishGuard authentication and protected app routes.
- Phishing analyzer, report generation, dashboard, tutor, vault, quiz, admin CMS, and PWA behavior.
