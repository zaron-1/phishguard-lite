# PhishGuard Lite Roadmap

## Active task — session recovery and Cyber Academy progression

- [ ] Recover persisted sessions after visibility changes, focus, sleep/wake, and temporary network loss without reloading the page.
- [ ] Preserve the current route, lesson, audio state, and progress while auth rehydrates.
- [ ] Extend Academy progression to Learning Path → Modules → Lessons → Subtopics → Quick Checks/Labs → Module Assessment.
- [ ] Grow active learning paths to a sustained five-month study plan without replacing the existing catalog.
- [ ] Automatically stop and load lesson audio on navigation, reading the lesson content and caching generated audio.
- [ ] Add lightweight lesson visuals only where they improve comprehension.
- [ ] Add backend-validated randomized module assessments, 80% unlock gates, retakes, and anti-copy friction.
- [ ] Enforce one active learning path until completion in backend/database rules.
- [ ] Autosave lesson, lab, module, and assessment progress for exact resume.

## Existing features to preserve

- PhishGuard authentication and protected app routes.
- Phishing analyzer, report generation, dashboard, tutor, vault, quiz, admin CMS, and PWA behavior.
